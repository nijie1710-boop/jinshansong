# 微信审核说明

## 一、版本用途

本次提交包含两个微信小程序：

- 金闪送用户端：面向消费者，用于浏览福州本地数码配件、管理收货地址、创建订单、查看订单状态、联系平台客服和查看协议隐私说明。
- 金闪送商家端：面向入驻门店，用于提交门店资料、查询审核状态、管理门店商品、维护库存、处理订单接单、查看配送状态、查看对账信息和联系平台。

后台管理系统为 Web 管理后台，不作为微信小程序提交审核内容。

## 二、支付和交易说明

当前版本支付能力为模拟支付，仅用于审核体验和业务流程演示。

- 用户端可以体验商品浏览、地址管理、下单流程和订单状态流转。
- 当前版本不会发起真实微信支付扣款。
- 当前版本不会产生真实交易结算。
- 后续完成备案、HTTPS、微信支付商户号和微信支付配置后，再切换到真实交易。

## 三、用户端审核路径

审核人员可按以下路径体验用户端：

1. 打开金闪送用户端小程序。
2. 点击“微信手机号快捷登录”完成授权或进入审核体验账号。
3. 进入首页，浏览推荐商品和分类商品。
4. 进入商品详情，查看商品信息。
5. 添加购物车或直接进入确认订单。
6. 新增或选择收货地址。
7. 提交订单，体验模拟支付后的订单状态。
8. 在“订单”查看订单列表和订单详情。
9. 在“我的”进入“关于我们 / 联系客服 / 隐私协议 / 用户协议”。

## 四、商家端审核路径

审核人员可按以下路径体验商家端：

1. 打开金闪送商家端小程序。
2. 在“审核状态”中输入审核专用商家手机号。
3. 点击“查看审核状态”。
4. 审核状态为“已通过”时，点击“进入商家端”。
5. 在商家首页查看待接单、今日订单、待发货、待结算等数据。
6. 进入“订单”查看订单列表和订单详情。
7. 进入“商品”查看商品、库存和上下架状态。
8. 进入“对账”查看结算数据。
9. 进入“设置”查看门店服务协议、隐私协议和联系平台入口。

## 五、商家端测试账号和测试门店

为避免真实手机号和经营资料进入公开代码仓库，提交微信审核前请在微信版本备注中填写最终审核专用账号。

建议准备如下审核专用数据：

- 商家端测试手机号：使用一个已在后台审核通过的专用手机号。
- 测试门店名称：金闪送审核测试门店。
- 测试门店状态：已审核通过、营业中。
- 测试门店商品：至少 2 个已审核通过且有库存的数码配件商品。
- 测试门店订单：至少准备 1 条可查看的测试订单，便于审核人员进入订单详情。

如使用初始化演示数据，本地种子数据中包含：

- 用户端演示手机号：13800000000。
- 演示门店编码：FZ-TAIJIANG-001。
- 演示门店名称：品胜福州宝龙店。

正式提审前，应以线上后台实际审核通过的专用商家手机号为准。

## 六、后台审核操作路径

平台管理员可通过 Web 后台完成审核准备：

1. 打开后台管理系统。
2. 进入“门店管理”。
3. 查看商家入驻申请。
4. 审核通过测试门店。
5. 进入“商品管理”。
6. 审核测试门店提交的商品。
7. 确认商品有库存且状态可售。
8. 进入“订单管理”查看测试订单。

## 七、提交审核版本备注建议

可在微信公众平台版本备注中填写：

```text
本版本为金闪送小程序审核体验版本。用户端用于消费者浏览数码配件、管理地址、提交模拟订单和查看订单状态；商家端用于入驻门店管理商品、库存、订单、对账和联系平台。当前版本支付为模拟支付，不发起真实微信支付扣款，不产生真实交易结算。商家端请使用审核专用手机号登录，测试门店为已审核通过门店。
```

提交审核时请把“审核专用手机号”和“测试门店名称”补充到版本备注中。
