# 金闪送生产部署说明

当前生产配置面向第一阶段 MVP：一台云服务器同时运行 API、后台、PostgreSQL、Redis 和 Nginx。等订单量上来后，再拆分数据库、对象存储和 CDN。

## 服务器准备

推荐最低配置：

- Ubuntu 22.04 或 24.04
- 2 核 4G
- 60G 硬盘
- 3M 带宽起步

需要安装：

```bash
docker --version
docker compose version
git --version
```

## 域名规划

品牌名和域名确认后，建议使用同一个主域名的子域名：

```txt
api.example.com      后端 API
admin.example.com    管理后台
assets.example.com   后续 COS/OSS/CDN 图片域名
```

小程序正式版必须在微信后台配置 `request`、`uploadFile`、`downloadFile` 合法域名。

## 首次部署

```bash
cd /opt
git clone <repo-url> jinshansong
cd /opt/jinshansong

cp .env.production.example .env.production
```

修改 `.env.production`：

- `API_DOMAIN`
- `ADMIN_DOMAIN`
- `DATABASE_URL`
- `POSTGRES_PASSWORD`
- `JWT_SECRET`
- `ADMIN_DEFAULT_PASSWORD`
- `NEXT_PUBLIC_API_BASE_URL`
- `VITE_MP_API_BASE_URL`
- `API_PUBLIC_BASE_URL`
- 两个小程序的 `AppID` / `AppSecret`

支付上线前继续保持 `PAYMENT_MODE=mock`。真实收款前再切换到 `PAYMENT_MODE=wechat`，并补齐：

- `WECHAT_PAY_MCH_ID`
- `WECHAT_PAY_API_V3_KEY`
- `WECHAT_PAY_SERIAL_NO`
- `WECHAT_PAY_PRIVATE_KEY_PATH`
- `WECHAT_PAY_NOTIFY_URL`

后台“设置”页会读取 `/api/health` 展示这些配置是否齐全；“系统配置”页只保存运营策略，不保存密钥。

启动数据库、Redis、API、后台：

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml up -d --build postgres redis api admin
```

备案通过前需要先用公网 IP 联调时，可临时暴露 API 和后台端口：

```bash
docker compose --env-file .env.production \
  -f docker-compose.prod.yml \
  -f docker-compose.preview.yml \
  up -d --build postgres redis api admin nginx-preview
```

临时预览地址类似：

```txt
http://服务器IP/api/health
http://服务器IP
```

该方式不能替代正式上线。小程序正式版、微信支付回调和用户访问都要等备案域名、DNS 和 HTTPS 完成。

检查 API 健康：

```bash
curl http://127.0.0.1:3001/api/health
```

初始化种子数据：

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml exec api pnpm db:seed
```

## Nginx 和 HTTPS

证书准备好后，启用 Nginx 代理：

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml --profile proxy up -d nginx
```

Nginx 模板在：

```txt
infra/nginx/jinshansong.conf.template
```

默认读取 Let's Encrypt 证书路径：

```txt
/etc/letsencrypt/live/<domain>/fullchain.pem
/etc/letsencrypt/live/<domain>/privkey.pem
```

如果使用腾讯云免费 SSL 证书，把证书放到同等路径，或按实际路径调整 Nginx 模板。

## 小程序构建

正式 AppID 和 HTTPS API 配好后：

```bash
pnpm wechat:real
pnpm check:miniapp
pnpm build:mp:real
```

然后在微信开发者工具导入：

```txt
apps/user-miniapp/dist/build/mp-weixin
apps/merchant-miniapp/dist/build/mp-weixin
```

## 回滚

如果某次部署失败：

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml logs api
docker compose --env-file .env.production -f docker-compose.prod.yml restart api admin
```

数据库回滚不要直接手动删表。先备份 PostgreSQL，再决定是否执行 Prisma 迁移回滚方案。
