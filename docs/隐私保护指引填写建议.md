# 隐私保护指引填写建议

## 一、用户端涉及的用户信息

金泽快送小程序建议在微信公众平台“用户隐私保护指引”中按实际使用情况勾选以下信息类型。

| 信息类型     | 使用目的                                           | 触发场景                           |
| ------------ | -------------------------------------------------- | ---------------------------------- |
| 手机号       | 用于账号登录、配送联系、售后核验、异常订单通知     | 微信手机号快捷登录、下单、订单售后 |
| 收货地址     | 用于订单配送、门店匹配、配送范围校验、订单履约     | 新增地址、确认订单、下单           |
| 位置信息     | 用于辅助填写地址、匹配附近可履约门店、判断配送范围 | 地址选择、定位选址、确认订单       |
| 订单信息     | 用于订单创建、订单状态查询、售后处理、风控核验     | 下单、订单列表、订单详情、售后     |
| 微信身份标识 | 用于识别用户账号、保持登录状态、关联订单记录       | 微信登录                           |

## 二、商户端涉及的用户信息

金泽快送商户端建议在微信公众平台“用户隐私保护指引”中按实际使用情况勾选以下信息类型。

| 信息类型       | 使用目的                                         | 触发场景                                 |
| -------------- | ------------------------------------------------ | ---------------------------------------- |
| 手机号         | 用于商户登录、入驻审核、门店联系人核验、平台联系 | 商户登录、提交入驻、审核状态查询         |
| 位置信息       | 用于门店地址选择、配送发单、门店服务范围判断     | 门店资料填写、定位选址                   |
| 身份或资质信息 | 用于商户入驻审核、经营资质校验、风险控制         | 上传营业执照、门店门头照、填写营业执照号 |
| 门店信息       | 用于门店展示、订单履约、配送取货、客服沟通       | 提交门店资料、后台审核、订单履约         |
| 订单信息       | 用于商户接单、备货、配送状态查看、结算对账       | 商户首页、订单管理、对账中心             |
| 微信身份标识   | 用于识别商户账号、保持登录状态、绑定已审核门店   | 微信登录                                 |

## 三、填写文案建议

### 手机号

使用目的建议填写：

```text
用于用户登录、配送联系、售后核验、订单异常通知；商户端用于入驻审核、账号登录和平台联系。
```

### 收货地址

使用目的建议填写：

```text
用于创建订单、匹配附近可履约门店、配送范围校验和同城配送履约。
```

### 位置信息

使用目的建议填写：

```text
用于辅助用户填写收货地址、判断配送范围、匹配附近门店；商户端用于填写门店地址和配送取货定位。
```

### 订单信息

使用目的建议填写：

```text
用于订单创建、订单状态查询、商户接单、配送履约、售后处理、对账结算和风控核验。
```

### 微信身份标识

使用目的建议填写：

```text
用于微信授权登录、识别账号身份、保持登录状态并关联订单、地址、门店和操作记录。
```

### 身份或资质信息

使用目的建议填写：

```text
用于商户入驻审核、经营资质校验、门店真实性核验和平台风险控制。
```

## 四、注意事项

- 隐私保护指引应分别在用户端和商户端小程序后台填写。
- 勾选的信息类型应与实际页面和接口保持一致，不要勾选未使用的信息。
- 如后续接入微信支付、真实配送平台或第三方客服，应补充支付、配送、客服相关的信息共享说明。
- 当前版本支付为模拟支付，不涉及真实扣款；接入微信支付后应同步更新隐私保护指引和用户协议。
